# Демонстрационный репозиторий для курса "Программирование"

Рекомендуемая структура репозитория:
- docs - с подпапками lab2,...,lab6. В каждой подпапке содержится _описание_ соответствующей лабораторной работы.
- project - папка, содержащая программную реализацию проекта.

Внутри папки project размещается main.py и подпапки:
- common - вспомогательные общие модули
- tests - тесты
